# Выбор модели под шаг

Перед первым планом или делегированием получить актуальный каталог моделей текущей платформы из
`/model`, доступного API/инструмента либо локального кэша. Идентификаторы не угадывать.

По текущим возможностям и накопленному опыту выбрать **две старшие модели**:

- более быструю и экономичную старшую — для обычной работы, типовой разработки, документации,
  команд, сбора данных, графа, коммита и пуша;
- самую сильную — для сложной диагностики, архитектуры, ИБ, необратимых операций и проверки результата.

Младшие и средние модели не использовать. Примеры линеек: Claude — Fable и Opus; Codex — Sol и
Astra; Gemini — две актуальные старшие модели своей линейки. Это не зашитые версии: в метках, командах
и отчётах всегда указывать точные актуальные идентификаторы собственной платформы.

Для Codex действует исключение с приоритетом над общими правилами выше и ниже: в доступном сейчас
каталоге `gpt-6-astra` — старшая для планирования, сложных решений, ИБ, необратимых действий и
итоговой проверки; `gpt-6-sol` — рабочая старшая; `gpt-6-luna` — младшая для безопасной рутины.
Перед выбором сверять актуальный каталог. Старшая модель составляет полный конкретный план всей
рутинной работы и передаёт его подагенту на `gpt-6-luna`; при доступном подагенте не выполняет
эту рутину сама. К `gpt-6-sol` переходить, если конкретный шаг не подходит для Luna, но не требует
Astra. Если подагенты недоступны, предложить пользователю `/model gpt-6-luna` после сверки каталога.

Если доступны подагенты с выбором модели, самодостаточные обычные шаги отдавать первой старшей, а
сложные оставлять второй. Иначе один раз предложить пользователю точную команду `/model <id>`.
Не переносить названия моделей между платформами.

Каждый шаг плана помечать точным идентификатором реально выбранной модели. Метка — обязательство:
шаг исполняется указанной моделью. Самостоятельное исключение допустимо только для шага короче примерно
трёх вызовов, которому нужен текущий контекст или который правит те же файлы; причину назвать пользователю.

Безопасность не зависит от модели: коммит и пуш — только после разрешения; боевой запуск — после
успешного dry-run и подтверждения; необратимые действия — только на самой сильной модели и с явным `да`.
