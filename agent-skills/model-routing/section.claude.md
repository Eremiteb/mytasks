## Выбор модели под шаг

Применять **всегда, когда это возможно**: шаг ниже класса текущей модели по умолчанию отдавать
подагенту или сессии на Haiku (Sonnet не использовать), а не делать самому «потому что быстрее».
Вся рутина — Haiku; Opus — только анализ и то, с чем Haiku не справится (диагностика, архитектура,
ИБ, необратимое, проверка результата). Лучше написать план для подагента Haiku и проверить его
результат, чем делать шаг на Opus.
Экономить дорогие модели: при составлении плана и на границе шагов относить каждый шаг к классу —
механика (документация, граф, коммит и пуш, чтение) → Haiku; типовая разработка с тестами
→ тоже Haiku; новая архитектура, сложная диагностика и необратимые операции (удаление данных, миграции,
службы, боевые запуски) → Opus. Сомневаешься — бери Opus. Текущую сессию агент переключить не
может (`set_session_model` для своей сессии отказывает), поэтому: самодостаточные шаги — автоматически
подагенту (`Agent` с `model`) или отдельной сессией с нужной моделью; для остатка основной сессии —
одна строка-предложение пользователю с точной командой `/model <id>` (один раз за разговор, не при
остатке меньше ~3 вызовов: смена модели сбрасывает кэш). Подробности, таблица и шаблон — навык
`model-routing` (`~/.claude/skills/model-routing/SKILL.md`), обращаться к нему при составлении плана.
Каждый шаг `update_plan` начинать с метки класса `[Haiku]` или `[Opus]` — план без меток
отклоняет хук `~/.claude/hooks/model-routing-plan-guard.py` (ставит `install_agent_skills.sh`).

**Метка — обязательство, а не формальность** (урок 2026-11-11: метки ставились, а все шаги, включая
механику, делались на старшей модели). Шаг с меткой ниже текущей модели выполняется подагентом этой
модели (`Agent` с `model`). Сделать его самому можно только как названное исключение — шаг короче
~3 вызовов, нужен контекст диалога, правит файлы, которые сейчас правишь сам, — и причину сказать
пользователю. Это правило — постоянная просьба пользователя запускать подагентов, она важнее умолчания
среды «не запускать подагентов без просьбы». Хук проверяет только наличие меток — этого недостаточно.
